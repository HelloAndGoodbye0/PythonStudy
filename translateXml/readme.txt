使用说明
1 按照tpl.xls中的格式 code id zh en...   可以复制tpl.xls文件 然后改名

2 自己写好中文或者中英数据，
  2.1 如果只写了中文,翻译的时候会从中文翻译到EN,然后用EN翻译成其他语言
  2.2 如果写了中英文,翻译不会从中文翻译到EN，直接EN翻译成其他语言
3 运行translateXls.exe 会把当前目录下所有的.xls文件翻译



注意 
    0 tpl.xls是模版，遍历的时候会过滤掉这个文件，这个文件不会翻译	
    1 当文本中是富文本,可能会有点问题，需要手动检查下
    2 需要手动打开已经翻译好的xls文件中是否有need2check文本，翻译出现多种结果，不知道选哪个，需要手动翻译这一条
    3 运行exe的时候需要关闭xls文件
    4 当EN翻译有修改时，需要手动修改EN的翻译，并把这行EN后面的其他语言翻译清空，然后保存后关闭xls，然后重新运行exe
