使用说明
1 按照tpl.xml中的格式写好 第一行的数据 code id zh en...   可以复制tpl.xml文件 然后改名

2 自己写好中文或者中英数据，
  2.1 如果只写了中文,翻译的时候会从中文翻译到EN,然后用EN翻译成其他语言
  2.2 如果写了中英文,翻译不会从中文翻译到EN，直接EN翻译成其他语言
3 运行translateXls.exe 会把当前目录下所有的xml文件翻译



注意 
    1 当文本中是富文本,可能会有点问题，需要手动检查下
    2 需要手动打开已经翻译好的xml文件中是否有need2check文本，翻译出现多种结果，不知道选哪个，需要手动检查 
    3 运行exe的时候需要关闭xml文件
